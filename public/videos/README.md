# Video loops

Drop short, seamless, muted loops here (2–3 seconds). Each slot accepts an .mp4 (required) and an optional .webm:

| Slot       | Files                          | Where it appears                         | Poster image (already in place)             |
| ---------- | ------------------------------ | ---------------------------------------- | ------------------------------------------- |
| interlude  | interlude.mp4 / interlude.webm | Home, full-bleed section after the carousel | /images/video-posters/interlude.jpg      |
| story      | story.mp4 / story.webm         | Home, "A session, felt"                  | /images/video-posters/story.jpg             |
| weddings   | weddings.mp4 / weddings.webm   | Services, inside the Weddings section    | /images/video-posters/weddings.jpg          |
| process    | process.mp4 / process.webm     | About, "Where it comes together"         | /images/video-posters/process.jpg           |
| contact    | contact.mp4 / contact.webm     | Contact page side panel                  | /images/video-posters/contact.jpg           |

Recommended: 1920×1080 (or 1080×1350 for portrait slots), H.264, no audio, under 2 MB, loop point checked.
Until a file exists, the poster photograph is shown with a slow cinematic zoom, so nothing looks broken.
Visitors who prefer reduced motion always see the still poster.
